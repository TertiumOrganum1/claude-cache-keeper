# Проверки

```sh
npm test              # нативные тесты Claude Code (claude plugin test)
npm run test:clock    # функции передачи отметки в штатный таймер
npm run test:repair   # установщик правки расширения на изолированных каталогах
npm run typecheck     # tsc --noEmit
npm run validate      # claude plugin validate --strict
npm run probe         # настоящий CLI против локального fake API
```

Ни одна проверка не отправляет платных запросов и не трогает установленное расширение.

## Что покрыто

- **`npm test`** - политика расписания и проверки usage (`hooks/policy.test.ts`) и адаптер плагина с GUI (`hooks/register.test.ts`) на нативных тестах Claude Code с подменённым временем: кнопки и команды, расписание прогрева, TTL, гонки с обычными ходами, ошибки и промахи, восстановление состояния, независимость чатов, реальные счётчики usage из логов, строка над полем ввода через `ui.mount`.
- **`test:repair`** - установщик (`scripts/check-auto-bridge.py`): без включения расширение не трогается, включение и правка новой версии, повторный запуск без чтения файла, переустановка той же версии, переименованные минифицированные переменные с исполнением сгенерированного кода, несовместимый bundle без записи, параллельный старт нескольких чатов, `--check` без изменений, `--disable` с возвратом оригиналов.
- **`test:clock`** - вспомогательные функции, которые вставляются в webview: чтение отметки прогрева и обновление записи счётчика.
- **`probe`** - запускает настоящий CLI с отдельным временным config и фиктивным API-ключом против локального HTTP-сервера. Проверяет, что прогрев, запущенный таймером, повторяет TTL, модель, инструменты, system prompt, effort и префикс сообщений обычного запроса, а при выключенном плагине запрос один со стандартным TTL. Usage синтетический.

## Что не покрыто автоматически

- Реальный срок хранения кэша у провайдера. Тесты проверяют, что прогрев отправлен и что usage подтверждает чтение из кэша; продление на час подтверждается только реальными логами.
- Живой интерфейс VS Code. Правка webview проверяется на копиях bundle; в открытом окне она начинает работать после `Developer: Reload Window`.

## Где смотреть реальные прогревы

Прогревы не попадают в транскрипт чата. Их usage пишется в лог расширения: `~/.config/Code/logs/<дата>/window*/exthost/Anthropic.claude-code/Claude VSCode.log`, строки `Forked agent [plugin_model_fork] finished ... totalUsage`.
